# API reference

Generated by `bun run meta` — do not edit by hand.

## Composables and helpers

### useTheme

Light/dark/system mode and brand color, saved in localStorage (nu-theme).

```ts
useTheme(): { theme: { mode, resolved, primary }, setMode(mode), toggleDark(), setPrimary(color | null), setDefaults({ mode, primary }) }
```

### useLayout

Layout options (topNav, boxed, fixedNavbar, fixedSidebar, fixedFooter, collapsed, rtl), saved in localStorage (nu-layout).

```ts
useLayout(): { layout, toggleSidebar(), setOption(key, value), setSidebarVariant('dark' | 'light'), setDefaults(), applyDirection(rtl), isMobile() }
```

### useToast

Fire toasts from anywhere; input is a message string or { title?, message, duration? }.

```ts
useToast(): { toasts, show(input, color?), success(input), error(input), warning(input), info(input), dismiss(id) }
```

### useForm

Form state and validation. `v-bind="form.field('email')"` wires value, update, blur validation and error into any Nu* input.

```ts
useForm(initial, schema): { values, errors, touched, submitting, isValid, validate(), validateField(name), reset(next?), field(name), handleSubmit(fn) }
```

### rules

Built-in validation rules; any (value, values) => true | message also works.

```ts
rules.required(msg?) | email(msg?) | minLength(n, msg?) | maxLength(n, msg?) | min(n, msg?) | max(n, msg?) | pattern(re, msg?) | sameAs(field, msg?)
```

### useLocale

Language of built-in text (en, id, or added), saved in localStorage (nu-locale).

```ts
useLocale(): { locale, setLocale(code), setDefaultLocale(code), addMessages(code, messages), t(key, params?) }
```

### useOverlay

Focus trap, scroll lock, Escape handling and focus restore for custom dialogs.

```ts
useOverlay(open: Ref<boolean>, panel: Ref<HTMLElement | null>, { onEscape? })
```

### filterMenu

Hide menu items (e.g. by item.meta.roles), dropping emptied groups and headers.

```ts
filterMenu(menu, (item) => boolean): NuMenuItem[]
```

### toCsv / downloadText

CSV from table columns (labels + format) and a browser download helper.

```ts
toCsv(rows, columns): string; downloadText(filename, text, type?)
```

### applyMask / unmask

Input masks: 9 digit, a letter, * either; other characters are literals.

```ts
applyMask(value, mask): string; unmask(value, mask): string
```

### createNusaAdmin

Vue plugin: applies defaults for first-time visitors and registers Nu* components globally (unless registerComponents: false).

```ts
createNusaAdmin({ theme?, primary?, sidebarVariant?, layout?, locale?, messages?, registerComponents? }): Plugin
```

## Shared types

- `NuMenuItem` = `{ label: string; icon?: Component; to?: RouteLocationRaw; href?: string; target?: string; badge?: string | number; badgeColor?: NuColor; children?: NuMenuItem[]; header?: boolean; color?: NuColor; meta?: Record<string, unknown> }`
- `NuTableColumn` = `{ key: string; label: string; sortable?: boolean; align?: 'left' | 'center' | 'right'; width?: string; format?: (value, row) => string }`
- `NuColor` = `'primary' | 'secondary' | 'success' | 'warning' | 'danger' | 'info'`
- `NuOption` = `{ label: string; value: string | number; disabled?: boolean }`
- `NuChartSeries` = `{ name: string; data: number[]; color?: string }`
- `NuTimelineItem` = `{ label?: string; title?: string; time?: string; description?: string; color?: NuColor; icon?: Component }`
