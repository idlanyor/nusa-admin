# nusa-admin agent skill

Teaches coding agents (Claude Code, Cursor, Codex, …) to build admin pages with the
[Nusa Admin](https://www.npmjs.com/package/nusa-admin) Vue kit: which component to use, real examples, page recipes
and the kit's conventions.

```bash
npx skills add idlanyor/nusa-admin
```

`references/` is generated from the kit source by `bun run meta` — don't edit it by hand.
