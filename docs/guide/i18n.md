# Languages and RTL

Built-in text — placeholders, labels for assistive technology, table summaries, validation messages, and date formatting — ships in English (`en`) and Indonesian (`id`).

```ts
app.use(createNusaAdmin({ locale: 'id' }))           // default for first-time visitors

const { setLocale, addMessages, t } = useLocale()
setLocale('en')                                      // saved in localStorage (nu-locale), sets <html lang>
addMessages('ms', { close: 'Tutup', search: 'Cari…' }) // new language; missing keys fall back to English
t('range', { from: 1, to: 10, total: 42 })            // "1–10 of 42"
```

Your own page copy is yours to translate (vue-i18n works fine alongside).

## Right-to-left

`<NuLayout rtl>` or `useLayout().setOption('rtl', true)` sets `<html dir="rtl">`. The kit uses logical CSS properties, so spacing, borders, the sidebar, drawers, dropdowns and toasts mirror automatically; directional icons flip. Charts, maps and code stay left-to-right.
